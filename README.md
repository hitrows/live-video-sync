# Live Video Sync

Видео на экране сцены синхронно с Logic Pro (или другой программой, которая шлёт MIDI Timecode — MTC).
MacBook с Logic шлёт таймкод по Wi-Fi (сетевой MIDI macOS) → M1 MacBook показывает нужное видео в нужном месте.

## Как это работает

- **Таймкод (MTC)** — Logic постоянно сообщает позицию курсора. Плеер держит видео ровно на ней: перемотал Logic — перемоталось видео.
- **Ноты-метки** — на отдельной MIDI-дорожке в начале каждой песни стоит короткая нота. У каждой песни сет-листа своя нота (новая песня получает следующую свободную: **C1**, **C#1**, **D1**…, сменить — «•••» → **Marker Note**). Плеер запоминает, в каком месте проекта начинается каждая песня. Достаточно один раз прогнать сет (или каждую песню с начала); после правки аранжировки метки обновятся сами при следующем проигрывании.
- **MMC Stop** — Logic сообщает «стоп» (в том числе автостоп). Плеер сразу уходит на логотип.

| Ситуация | На экране |
|---|---|
| Курсор внутри песни | Видео песни, синхронно |
| Видео кончилось, Logic ещё играет | Fade-out → логотип по кругу |
| Между песнями, до первой песни | Логотип |
| Стоп / автостоп | Fade-out → логотип |
| Пропала связь посреди песни | Видео доигрывает само → потом логотип |
| Связь вернулась | Снова держится за таймкод |
| Программа упала или зависла | Перезапускается сама за ~1 с, трансляция возвращается |

## Сеты, Extras, Screen Fit

- **Сет-лист собирается в программе**: **File** → **New Setlist**, видео перетащить в список. Файлы лежат где угодно, порядок — перетаскиванием. Играет **активный** сет (метка **Active**, другой — **Make Active**). Старая папка `01_…`, `02_…` при первом запуске сама превращается в сет с выученными метками.
- **Trim…** — играть только кусок файла (файл не меняется). У обрезанной песни — значок ножниц.
- **Extras** — плейлисты логотипов групп, рекламы, интро: общие для всех сетов, **Play**, **Repeat Off / All / One**, видео со звуком. Новая песня из Logic перебивает Extras. Правый щелчок по файлу → **Set as Logo**.
- **Screen Fit** — подгонка всего вывода под экран площадки, как в Final Cut: **Transform / Crop / Distort**, **Test Pattern**, пресеты площадок.
- Логотип: **Settings** → **Output** → **Logo** (видео или картинка), играет по кругу.
- H.264, 24 или 25 к/с, лучше с ключевым кадром раз в секунду (быстрая перемотка). У песен сет-листа звук не играет (он из Logic), у Extras — играет.

## Настройка (один раз)

### 1. Сетевой MIDI
Названия меню — как в английской macOS.
1. **Один раз на каждом Mac**, если там ещё нет сетевого сеанса: **Audio MIDI Setup** → **Window** → **Show MIDI Studio** → двойной клик по **Network** → под **My Sessions** нажать **+**, поставить галочку у **Session 1**. Сеанс сохраняется в системе навсегда. (На Mac mini и MacBook уже сделано.)
2. Дальше Audio MIDI Setup не нужна:
   - на **MacBook с Logic** — утилита **MIDI Link** (`~/Applications/MIDILink.app`): выбрать Mac с видео → **Connect**. Утилиту можно закрыть — связь остаётся;
   - или на **Mac с видео** — **Settings** → **Sync** → **Source Mac** (или меню у строки «Source: …» под Now Playing). Плеер запоминает выбор и **сам переподключается**, если связь пропала (Wi-Fi моргнул, MacBook перезагрузили).
3. Под Now Playing зелёная точка и «Source: … · connected» — связь есть. Если нет — кнопка **?** рядом откроет, что проверить.

Сетевой сеанс работает, пока на Mac запущена хоть одна MIDI-программа (Logic, Live Video Sync, MIDI Link): иначе macOS выключает MIDI-службу.

### 2. Logic
1. **File** → **Project Settings** → **Synchronization**:
   - вкладка **General**: **Frame Rate** = **24** или **25**;
   - вкладка **MIDI**: включить **Transmit MTC** и **Transmit MMC**, назначение — **Session 1** (сетевой сеанс).
2. **Track** → **New Track** → **External MIDI**, выход (**Port**) — **Session 1**.
3. В начале каждой песни поставить короткую ноту — ту, что видна у песни в сет-листе (первая нота для новых песен: **Settings** → **General** → **First marker note**).
4. Прогнать сет или каждую песню с начала — ноты в сет-листе станут яркими (выучены).

### 3. Программа на M1
1. Скопировать `LiveVideoSync.app` в «Программы».
2. Первый запуск: правый клик → **Open** → **Open** (программа без подписи Apple). Если macOS не даёт — **System Settings** → **Privacy & Security** → **Open Anyway**.
3. macOS спросит доступ к локальной сети — **Allow** (иначе не будет связи с Logic).
4. **Settings** (Cmd+,) → **Output**: экран сцены («First external display» — первый внешний), разрешение, логотип, картинка на время перезапуска. **Sync**: Source Mac.
5. **Go Live**. Настройки запоминаются; при следующем запуске вывод включится сам. Кнопка с окном слева от Go Live — вывод в тестовое окно на этом Mac.

## Масштаб видео

Пропорции видео всегда сохраняются — видео не растягивается.

| Режим | Что делает |
|---|---|
| **Fit** | Видео целиком; если пропорции экрана другие — чёрные полосы |
| **Fill** | Экран заполнен полностью, лишнее обрезается |
| **Fit height** | Высота видео = высота экрана; лево/право обрезаются (или полосы по бокам) |
| **Fit width** | Ширина видео = ширина экрана; верх/низ обрезаются (или полосы сверху и снизу) |

Режим — **Settings** → **Output** → **Scale**; точная подгонка под экран площадки — **Screen Fit**.

## Клавиши

| | |
|---|---|
| Cmd+L | Go Live / Stop Output (остановка — с подтверждением, только щелчком) |
| Cmd+G | Logo (держится до Resume Sync) |
| Cmd+B | Blackout (держится до Resume Sync) |
| Cmd+R | Resume Sync — снова то, что играет в Logic |
| Cmd+T | Test Pattern на экране сцены |
| Cmd+1 / Cmd+2 | Show / Screen Fit |
| Cmd+N / Shift+Cmd+N | Новый сет / новый плейлист Extras |
| Cmd+Q | Выход (спросит; экран сцены погаснет) |

Закрыть окно управления можно — трансляция продолжится.

## Чек-лист перед концертом

- [ ] M1 на зарядке, проектор подключён, в **System Settings** → **Displays** — расширенный рабочий стол (не **Mirror**).
- [ ] Включён **Focus** → **Do Not Disturb** на M1 (уведомления программа отключить не может).
- [ ] Wi-Fi 5 ГГц, оба Mac в одной сети; под Now Playing — «Source: … · connected».
- [ ] Нужный сет — **Active**; в заголовке окна «LIVE · <проектор>», логотип на экране.
- [ ] **Screen Fit** → **Test Pattern**: красная рамка видна целиком, выбран пресет площадки; Test Pattern выключен.
- [ ] Прогон первой песни в Logic: видео идёт, «Locked to MTC», drift около 0.

## Сборка и проверка (для разработки)

```bash
./test.sh                                   # тесты логики
./build.sh                                  # build/LiveVideoSync.app + утилиты
./build/make-test-videos TestVideos 12 12   # тестовые видео с таймером на кадре
./build/mtc-emulator TestVideos             # эмулятор Logic (help — команды)
```

Лог: `~/Library/Logs/LiveVideoSync/lvs.log`. Настройки и сеты: `~/Library/Application Support/LiveVideoSync/settings.json`; что вернуть на экране сцены при выходе (обои, разрешение): `stage.json` там же.
