# Live Video Sync

Видео на экране сцены синхронно с Logic Pro по MIDI Timecode (MTC).
MacBook с Logic шлёт таймкод по Wi-Fi (сетевой MIDI macOS) → M1 MacBook показывает нужное видео в нужном месте.

## Как это работает

- **Таймкод (MTC)** — Logic постоянно сообщает позицию курсора. Плеер держит видео ровно на ней: перемотал Logic — перемоталось видео.
- **Ноты-метки** — на отдельной MIDI-дорожке в начале каждой песни стоит короткая нота: песня 1 — **C1**, песня 2 — **C#1**, песня 3 — **D1**… Плеер запоминает, в каком месте проекта начинается каждая песня. Достаточно один раз прогнать сет (или каждую песню с начала); после правки аранжировки метки обновятся сами при следующем проигрывании.
- **MMC Stop** — Logic сообщает «стоп» (в том числе автостоп). Плеер сразу уходит на логотип.

| Ситуация | На экране |
|---|---|
| Курсор внутри песни | Видео песни, синхронно |
| Видео кончилось, Logic ещё играет | Fade-out → логотип по кругу |
| Между песнями, до первой песни | Логотип |
| Стоп / автостоп | Fade-out → логотип |
| Пропала связь посреди песни | Видео доигрывает само → потом логотип |
| Связь вернулась | Снова держится за таймкод |
| Программа упала или зависла | Перезапускается сама за ~1 с, трансляция возвращается |

## Видео

- Одна папка. Песни: `01_Название.mp4`, `02_Название.mp4`, … — номер в начале имени = номер песни = нота-метка.
- Логотип: любой файл со словом `logo` в имени (`logo.mp4`), играет по кругу.
- H.264, 25 к/с, лучше с ключевым кадром раз в секунду (быстрая перемотка). Звук в видео не играет.
- Видео начинается ровно со старта песни (с ноты-метки).

## Настройка (один раз)

### 1. Сетевой MIDI
Названия меню — как в английской macOS.
1. **Один раз на каждом Mac**, если там ещё нет сетевого сеанса: **Audio MIDI Setup** → **Window** → **Show MIDI Studio** → двойной клик по **Network** → под **My Sessions** нажать **+**, поставить галочку у **Session 1**. Сеанс сохраняется в системе навсегда. (На Mac mini и MacBook уже сделано.)
2. Дальше Audio MIDI Setup не нужна:
   - на **MacBook с Logic** — утилита **MIDI Link** (`~/Applications/MIDILink.app`): выбрать Mac с видео → **Connect**. Утилиту можно закрыть — связь остаётся;
   - или на **Mac с видео** — в Live Video Sync строка **Logic Mac** → **Connect**. Плеер запоминает выбор и **сам переподключается**, если связь пропала (Wi-Fi моргнул, MacBook перезагрузили).
3. В окне Live Video Sync зелёная точка и «Network: …» — связь есть.

Сетевой сеанс работает, пока на Mac запущена хоть одна MIDI-программа (Logic, Live Video Sync, MIDI Link): иначе macOS выключает MIDI-службу.

### 2. Logic
1. **File** → **Project Settings** → **Synchronization**:
   - вкладка **General**: **Frame Rate** = **25**;
   - вкладка **MIDI**: включить **Transmit MTC** и **Transmit MMC**, назначение — **Session 1** (сетевой сеанс).
2. **Track** → **New Track** → **External MIDI**, выход (**Port**) — **Session 1**.
3. В начале каждой песни поставить короткую ноту: C1 — песня 1, C#1 — песня 2 и т.д. (первая нота меняется в окне программы: «First song marker»).
4. Прогнать сет или каждую песню с начала — в таблице появятся «Starts in Logic».

### 3. Программа на M1
1. Скопировать `LiveVideoSync.app` в «Программы».
2. Первый запуск: правый клик → **Open** → **Open** (программа без подписи Apple). Если macOS не даёт — **System Settings** → **Privacy & Security** → **Open Anyway**.
3. macOS спросит доступ к локальной сети — **Allow** (иначе не будет связи с Logic).
4. Выбрать папку с видео, экран («First external display» — первый внешний), режим масштаба.
5. **GO LIVE**. Настройки запоминаются; при следующем запуске трансляция включится сама.

## Масштаб видео

Пропорции видео всегда сохраняются — видео не растягивается.

| Режим | Что делает |
|---|---|
| **Fit** | Видео целиком; если пропорции экрана другие — чёрные полосы |
| **Fill** | Экран заполнен полностью, лишнее обрезается |
| **Fit height** | Высота видео = высота экрана; лево/право обрезаются (или полосы по бокам) |
| **Fit width** | Ширина видео = ширина экрана; верх/низ обрезаются (или полосы сверху и снизу) |

Переключать можно в любой момент, в том числе в эфире: кнопки в окне или Cmd+1…4.

## Клавиши

| | |
|---|---|
| Cmd+L | В эфир / остановить трансляцию |
| Cmd+B | Затемнение (вкл/выкл) |
| Cmd+G | Логотип вручную (снимается следующей песней) |
| Cmd+1…4 | Масштаб: Fit / Fill / Fit height / Fit width |
| Cmd+Q | Выход (спросит; экран сцены погаснет) |

Закрыть окно управления можно — трансляция продолжится.

## Чек-лист перед концертом

- [ ] M1 на зарядке, проектор подключён, в **System Settings** → **Displays** — расширенный рабочий стол (не **Mirror**).
- [ ] Включён **Focus** → **Do Not Disturb** на M1 (уведомления программа отключить не может).
- [ ] Wi-Fi 5 ГГц, оба Mac в одной сети; в Live Video Sync — зелёная точка.
- [ ] Окно программы: «Live on <проектор>», логотип на экране.
- [ ] Прогон первой песни в Logic: видео идёт, «locked to MTC», drift около 0.

## Сборка и проверка (для разработки)

```bash
./test.sh                                   # тесты логики
./build.sh                                  # build/LiveVideoSync.app + утилиты
./build/make-test-videos TestVideos 12 12   # тестовые видео с таймером на кадре
./build/mtc-emulator TestVideos             # эмулятор Logic (help — команды)
```

Лог: `~/Library/Logs/LiveVideoSync/lvs.log`. Настройки: `~/Library/Application Support/LiveVideoSync/settings.json`.
