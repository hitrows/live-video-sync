# Live Video Sync — заметки для Claude Code

Витя (гитарист группы sila). Видео на экране сцены синхронно с Logic по MTC. Подробности для пользователя — README.md.

## Правила
- Сначала предложение → «Делаем?» → ждать ответа. Имена файлов/папок/таргетов — английские; общение, комментарии, документация — русские. UI — английский (как в DMXBright).
- У Вити все Mac и iPhone на английском: в инструкциях названия меню/кнопок — по-английски, как на экране.
- Дизайн — по образцу приложений Apple (Music, Final Cut, Keynote) и официального macOS UI Kit. QLab и Resolume как образец дизайна НЕ использовать (Витя считает их дизайн помойкой); технические идеи оттуда брать можно.
- Софт для живого концерта: надёжность важнее фич. Никогда не чёрный экран по ошибке — лучше логотип или последний кадр.

## Железо
- **Mac mini** (здесь) — код, сборка, тесты с эмулятором. Один монитор → проверка в «Window (test)».
- **MacBook Pro 2014**, Big Sur 11.7.10 — Logic + ShowBuddy (свет, проект DMXBright). SSH: `ssh macbook`.
- **M1 MacBook**, macOS 15.7, 16 ГБ — плеер, выход на проектор клуба (1040×640). SSH не настроен.

## Устройство
- `Sources/Core` — без AppKit/AVFoundation, покрыто `./test.sh`: UMP-парсер, MTC (quarter frame, full frame, MMC), `MTCClock` (максимум смещения за 2 с против сетевого джиттера), `Director` (логика шоу, выучивание меток по нотам).
- **Сетевой MIDI на macOS:** `MIDINetworkSession` (API для iOS) на Mac ничего не делает. Сеансы — сущности устройства «Network» (драйвер AppleMIDIRTPDriver / AppleMIDINetworkDriver), настройки — словарь `apple.midirtp.session` на сущности (`dns-sd-name`, `port`, `join-policy` 2 = все, `flags` бит 0 = включён, `peers`, `persistent-peers`). Запись этого свойства применяется сразу. Создать новый сеанс записью свойства нельзя — один раз «+» в Audio MIDI Setup.
- `Sources/LiveVideoSync` — `VideoEngine` (2 слота песен + логотип-лупер, переход только когда у нового слоя есть кадр), `OutputWindow` (экран, горячее подключение, курсор), `Show` (связка, таймер 60 Гц), `Watchdog` (тот же бинарник с `--watchdog`: перезапуск при падении/зависании >8 с), `ControlView` (SwiftUI).
- Сборка: `build.sh` — напрямую `swiftc`, arm64, macOS 15, ad-hoc подпись.

## Проверено с реальным Logic (23.10.2026, MacBook → Wi-Fi → Mac mini)
- MTC, ноты-метки, переключение песен — работают, расхождение ~0 мс.
- **Logic не шлёт MMC Stop** — при Play и при Stop (и автостопе) он шлёт **MMC Locate** (F0 7F 7F 06 44 06 01 hh mm ss ff sf F7). Стоп = таймкод замолчал сразу после Locate → логотип. Таймкод пропал без Locate → обрыв связи, песня доигрывает.
- Сетевой MIDI: MIDI Link на MacBook подключает, связь остаётся после её закрытия; плеер сам переподключается к Logic Mac.
- Вывод на второй экран (LG PROJECTOR 1680×1050, подключён к Mini) — трансляция ушла на него автоматически.

## Не проверено
- Отключение/подключение проектора во время эфира.
- M1: установка, разовое создание сеанса в Audio MIDI Setup, запрос доступа к локальной сети.
- Видео 24 к/с с проекта Вити (тесты были на 25).

## Запланировано (по итогам концерта 24.10.2026)
- **Screen Fit:** область вывода (видимая часть экрана площадки + рамка видео, без/с сохранением пропорций), тестовая сетка на сцене, пресеты площадок.
- **Extras:** плейлисты как в Apple Music — пользователь сам создаёт и называет («Логотипы групп», «Реклама»), файлы перетаскиваются, порядок меняется перетаскиванием; плейлисты общие для всех сетов; у плейлиста ▶ Play и повтор, у строки свой ▶. Картинка показывается бесконечно, пока не придёт другое (песня по таймкоду, Logo/Blackout, другой файл). Кнопка повтора как в Apple Music: Off / Repeat All (все Extras по порядку по кругу; картинки — по одной общей длительности на все Extras (одна настройка, по умолчанию 10 с), отдельной у каждой картинки нет) / Repeat One (один файл по кругу).
- **Новый интерфейс** по макету в Figma (копия macOS 27 UI Kit в аккаунте Кристины, страница «Live Video Sync», вариант «Show v2 — Music-style setlist»): сет-лист как список треков Apple Music (номер → эквалайзер у играющей, ▶ при наведении, значок ноты-метки, точка-предупреждение: оранжевая — проблема с файлом, серая — метка не выучена), библиотека Setlists/Extras в боковой панели. Плавающую капсулу-плеер НЕ делать.
- **Resume Sync** — кнопка «вернуть управление Logic»: снимает ручной режим (Logo / Blackout / ручной ▶) и сразу показывает то, что играет по таймкоду. Название выбрал Витя.
