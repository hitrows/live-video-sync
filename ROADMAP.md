# Live Video Sync — дорожная карта

Составлено после концерта 23.10.2026. Порядок работы:

1. **Логика экранов** — расписать, что на каждом экране есть и как оно себя ведёт (этот файл, раздел «Экраны»).
2. **Дизайн в Figma** — по утверждённой логике, на компонентах Apple macOS 27 UI Kit (файл-копия набора в аккаунте Кристины, страница «Live Video Sync»).
3. **Программа** — по утверждённому дизайну.

Тестируем на **Mac mini**: окно «Window (test)» вместо проектора, эмулятор Logic (`build/mtc-emulator`) и настоящий MacBook с Logic по сети. На M1 выкладываем только проверенное (`deploy-m1.sh`).

Дизайн — только по образцу приложений Apple (Music, Final Cut, Keynote) и macOS UI Kit. QLab и Resolume как образец внешнего вида не используем.

## Правила воспроизведения

| Что | Как играет |
|---|---|
| Песня сет-листа (видео) | По таймкоду Logic; видео кончилось раньше песни → логотип |
| Картинка в сет-листе (вместо видео песни) | Висит бесконечно, пока не придёт другой сигнал |
| Одиночный запуск файла (▶ у строки) | Видео — до конца, потом логотип; картинка — бесконечно |
| Плейлист Extras, Repeat Off | Файлы по порядку один раз; картинки показываются по **одной общей длительности для всех Extras** (одна настройка, применяется ко всем картинкам автоматически; по умолчанию 10 с); после последнего — логотип |
| Плейлист Extras, Repeat All | То же, но по кругу |
| Плейлист Extras, Repeat One | Один выбранный файл по кругу (картинка — просто висит) |
| Стоп в Logic (MMC Locate) | Логотип |
| Обрыв связи посреди песни | Видео доигрывает само, потом логотип |
| Logo / Blackout (вручную) | Держится, пока не нажмут Resume Sync, снова Logo/Blackout или не придёт новая песня из Logic |
| **Resume Sync** | Снимает ручной режим (Logo, Blackout, ручной ▶, Extras) — сразу показывает то, что сейчас играет в Logic |

«Другой сигнал» для картинки: новая песня по таймкоду или ноте-метке, Stop в Logic, Logo, Blackout, Resume Sync, запуск другого файла или плейлиста.

## Экраны (логику расписываем первым шагом)

### Решения по логике (25.10.2026)
1. Клик по песне — только выделение; ручной запуск — двойной клик или ▶ при наведении.
2. Пилюля **● Live** = включить/выключить вывод на экран сцены (бывшая GO LIVE).
3. Клик по сету в боковой панели — только открывает его; **сделать активным** — отдельное действие. Активный сет помечен значком (как играющий плейлист в Music).
4. **Сет собирается в программе**: видео перетаскиваются в список, номер = порядок, файлы могут лежать где угодно (не папка с номерами).
5. Меню «•••» у песни: **Replace File…**, **Change Duration…**, **Reset Marker**, **Show in Finder**, **Remove from Setlist**.
   - **Change Duration…** — окно обрезки как в Фото (лента кадров с жёлтыми ручками начала/конца, ▶ для просмотра). Файл не меняется: задаются точки начала и конца; при старте песни по метке видео идёт с точки начала и кончается в точке конца. Сбросить — вернуть полную длину.
6. Превью = ровно то, что на проекторе, с учётом Screen Fit.

### Решения по Extras и Setup (25.10.2026)
1. Песня из Logic (по таймкоду/метке) перебивает играющий Extras.
2. **Звук в роликах Extras играет** (у песен сет-листа звука нет — он из Logic). В Setup: выход звука и громкость Extras.
3. Перетаскивание файлов между плейлистами Extras и сет-листом — сделать (не обязательно, но желательно).
4. **Нота-метка = позиция в списке** сета (1 — C1, 2 — C#1 …). Поменял порядок — двигаешь ноты в Logic.
5. Setup: связь с Logic Mac, **переход: Fade (через чёрное) / Crossfade / Cut + длительность**, нота первой песни, экран вывода, выход звука Extras, лог и инструкция.
6. **Обои экрана трансляции**: при выходе в эфир программа ставит на этот экран выбранную картинку (или кнопка «Black») — если программа упадёт, пока она перезапускается, на проекторе будут эти обои, а не рабочий стол. При штатном выходе — вернуть прежние обои.
7. **Dock и строка меню на экране трансляции**: пока программа работает, её окно и так закрывает их. Чтобы их не было и во время перезапуска после сбоя — системная настройка macOS (Displays have separate Spaces → выкл, основной экран — встроенный); программа проверяет её в Setup и подсказывает, что включить.

### Show — концерт
- Панель инструментов: переключатель **Show / Screen Fit / Setup**, заголовок со статусом эфира, поиск по сет-листу, кнопка боковой панели.
- Боковая панель — библиотека: **Setlists** (каждая папка с видео — свой сет со своими метками) и **Extras** (плейлисты).
- Сверху: превью экрана сцены (LIVE, формат, время) и блок **Now Playing**: номер, название, Locked to MTC / сама / вручную, прогресс, Next, кнопки **Logo**, **Blackout**, **Resume Sync**, строки статуса (Logic, выход).
- Снизу: сет-лист в стиле Apple Music — номер (у играющей — эквалайзер, при наведении ▶), название, значок ноты-метки, точка-предупреждение (оранжевая — проблема с файлом, серая — метка не выучена; подсказка при наведении), длительность, «•••» (заменить файл, сбросить метку, показать в Finder).
- Шапка сета: название, «N songs · M min · папка», пилюля **● Live**.
- Плавающую капсулу-плеер не делаем.

### Extras — открытый плейлист (в той же основной области, что и сет-лист)
- Шапка: название плейлиста, число файлов, **▶ Play**, повтор **Off / Repeat All / Repeat One**, поле **Image duration** — одна настройка на все Extras (меняешь в любом плейлисте — меняется везде).
- Строки: ▶, миниатюра, имя, тип (видео / картинка), длительность (у картинки — общая длительность Extras, отдельно не настраивается), «•••».
- Файлы перетаскиваются в плейлист; порядок — перетаскиванием; новый плейлист — «+» в боковой панели или File → New Playlist.
- Плейлисты общие для всех сетов.

### Screen Fit — подгонка под экран площадки (как в Final Cut)
Подгонка применяется **ко всему выводу на проектор**: все песни, Extras, логотип. Сохраняется пресетом площадки.

- **Большое превью = холст выхода.** Клик по видео — вокруг кадра рамка с синими ручками (как экранные элементы Final Cut):
  - середина — двигать по экрану; угловые/боковые ручки — масштаб (Shift — с пропорциями); ручка на «усике» от центра — поворот.
  - Режимы над превью: **Transform** / **Crop** (обрезать края) / **Distort** (тянуть каждый угол — трапеция под проектор под углом).
- **Инспектор справа с точными числами:**
  - **Transform**: Position X/Y, Rotation, Scale (All), Scale X, Scale Y, Anchor X/Y.
  - **Crop**: Left, Right, Top, Bottom.
  - **Distort**: Bottom Left, Bottom Right, Top Right, Top Left — X/Y.
  - У каждой группы — галочка вкл/выкл и Reset.
- **Кнопка «Test Pattern»** на этом экране — включает на проекторе сетку с координатами и рамкой по краю, чтобы увидеть, какая часть картинки реально видна.
- **Пресеты площадок**: выбрать, сохранить как…, Reset.
- Правки применяются на лету, в том числе в эфире. На экране **Show** превью только для просмотра — там случайно сдвинуть картинку нельзя.
- Позже, если понадобится: подгонка отдельной песни («•••» → Adjust Frame…).

### Setup — настройки
- Папка с видео (сет), пересканировать, предупреждения по файлам.
- Logic Mac: выбор, Connect, статус, последний IP, «MIDI только из сетевого сеанса».
- Переходы: через чёрное / кроссфейд, fade out / fade in.
- Метки: нота первой песни, сброс меток.
- Экран вывода.
- Лог и инструкция (?).

## Правки дизайна по гайдам Apple (25.10.2026)
- **Настройки — отдельное окно Settings** (Live Video Sync → Settings…, Cmd+,), вкладки **General / Logic / Output / Help**, один столбец блоков. В переключателе режимов только **Show | Screen Fit**.
- **Панель инструментов**: заголовок слева, **Show | Screen Fit** по центру (серое выделение, как на панели у Apple), справа **Go Live / Stop Output** и поиск. Включение вывода — на панели, а не в шапке сета.
- **Шапка сета**: у активного — метка **● Active**; у открытого неактивного — кнопка **Make Active**.
- **Change Duration → Trim…** (как в QuickTime и Фото): пункт меню, заголовок окна, кнопка подтверждения. Окно-лист по центру окна под панелью инструментов.
- **Предупреждения** — значок ⚠︎ с подсказкой (не только цвет).
- **Строки статуса** — серый текст и цветная точка.
- **Resume Sync** — выделенная только в ручном режиме, иначе неактивна.
- **Extras**: «Repeat» + переключатель **Off | All | One**; длительность картинок — в **Settings → General → Extras** (в шапке — «Images: 10 s each»); у видео со звуком — значок динамика.
- **Screen Fit**: **Test Pattern** — кнопка-переключатель; оранжевую «видимую область» убрали (видимую часть показывает тестовая сетка на проекторе).
- **«+» внизу боковой панели** (новый сет / плейлист), как в Music.
- **Цвета**: красный — только «в эфире» (LIVE, играющая песня, активный сет, Stop Output); остальное — системный синий.
- **Значок активного сета** — «экран с ▶» (не динамик: у песен звука нет).
- **Играющая песня** — красный значок плёнки, по которому бегут кадры (анимация в программе; в Figma — статичный значок). Эквалайзер не используем: он про звук.
- **Переименование в списке** (только отображаемое имя, файл не меняется): выделить строку → **Return** — название становится полем; или **Rename** в меню «•••» / по правому клику (одно и то же меню). Двойной клик — ручной запуск.
- **Change Marker ▸** в меню «•••»: подменю позиций «1 · C1, 2 · C#1 …» с галочкой у текущей; выбор переносит песню на эту позицию (остальные сдвигаются). Перетаскивание строк тоже меняет позиции и ноты. После переноса — напоминание «передвинь ноту в Logic».
- **Меню «•••»**: Rename, Trim…, Change Marker ▸ | Replace File…, Reset Marker, Show in Finder | Remove from Setlist (красным). У края окна меню открывается вверх.
- **Проблема с файлом** — тонкий серый контурный треугольник SF Symbols `exclamationmark.triangle` (как в Finder и Xcode; не жёлтый, не залитый), подсказка при наведении, по щелчку — окно с решением.
- **Change Marker → Move to Position ▸** (название говорит, что песня переедет).

## Правки дизайна по гайдам Apple — второй проход (25.10.2026)
- **Меню**: пункты не красятся в красный (кроме Remove from Setlist); «•••» у строки видно только при наведении.
- **Logo / Blackout** — кнопки-переключатели (нажата = включено), а не обычные кнопки.
- **Строка меню программы**: Live Video Sync, File, Edit, View, **Show**, Window, Help. Меню **Show**: Stop Output / Go Live **⌘L**, Logo **⌘G**, Blackout **⌘B**, Resume Sync **⌘R** | Test Pattern **⌘T** | Show **⌘1**, Screen Fit **⌘2**.
- **Stop Output** — с подтверждением: Cancel — обычная серая кнопка (Esc), Stop Output — красная. Return окно не закрывает: остановить вывод можно только щелчком, случайно нажать нельзя.
- **Нет связи с Logic** — баннер под панелью инструментов + оранжевая/красная точка в статусе, песня доигрывает.
- **Вывод выключен** — на превью метка OFF и затемнение «stage screen shows the wallpaper», на панели синяя **Go Live**.
- **Открыт неактивный сет** — кнопка **Make Active** и подсказка, какой сет сейчас играет.
- **Первый запуск** — пустое состояние «No Setlists Yet» + **New Setlist**.
- **Screen Fit**: без поиска; **Reset All** на панели; у каждой группы инспектора — кнопка сброса ↺; меню пресетов: список пресетов с галочкой | **Save as Preset… / Rename Preset… / Delete Preset…**
- **Окно Settings**: кнопки свернуть/развернуть серые (окно настроек не масштабируется).
- **Extras**: зона «перетащи файлы» только в пустом плейлисте.
- Экран вывода везде называется одинаково (например «A200 HDMI»).

## Дизайн — третий проход (25.10.2026)
- **Нет экрана сцены** — баннер «Stage display not found…» + **Display Settings…**, на превью затемнение «A200 HDMI not connected — waiting for the display», в заголовке «Waiting for display…». Шоу продолжает идти; экран подхватывается сам.
- **Нет сетевого MIDI-сеанса** — баннер с объяснением и кнопкой **Open Audio MIDI Setup**; вывод работает (логотип), статус «Waiting for Logic». Показывается только когда сеанса нет (не шаг первого запуска).
- **Файл не найден** — как в Apple Music: значок ⚠︎ у строки, по щелчку окно «The original file could not be found» — **Locate…** (по умолчанию, сверху) / **Cancel**.
- **Settings → Output**: Display, Hide Dock on stage display, Hide pointer; «While the Player Restarts»: Stage screen shows (Image / Black) + Image.
- **Settings → Logic**: Mac with Logic (с состоянием связи), Network MIDI session (только показ), Frame rate (из Logic), Accept MIDI only from Logic Mac.
- **Меньше дублей**: в Now Playing одна строка статуса Logic (Fade/Venue/Watchdog и Output убраны — они в Settings и на панели); в заголовке окна только «LIVE · A200 HDMI».
- В программе — системные стили текста macOS (основной 13 pt, мелкий не меньше 11 pt).
- **Нота-метка — отдельная колонка перед временем** (фиксированная ширина, плашки выровнены по левому краю, все ноты ровно друг под другом), как дополнительные колонки в Apple Music. Слева только номер/значок и название.

## Разрешение экрана сцены (решение 25.10.2026)
- **Settings → Output → Resolution**: «Default» + все режимы, которые сообщает экран, включая скрытые (`CGDisplayCopyAllDisplayModes` с `kCGDisplayShowDuplicateLowResolutionModes`), с частотой. Переключение — `CGDisplaySetDisplayMode` (официальный API, без прав администратора).
- После выбора — окно **Keep this resolution?** с отсчётом 15 с: **Keep** / **Revert**; без ответа режим возвращается сам.
- Режим запоминается для каждого экрана и ставится снова при подключении; при выходе из программы возвращается системный.
- Произвольные разрешения, которых экран не объявляет (подмена EDID, виртуальные экраны, как в SwitchResX / BetterDisplay), **не делаем**: закрытые API, ломаются с обновлениями, риск чёрного экрана. Нестандартную видимую область решает Screen Fit.
- **Active — серая плашка без точки** (активный сет ≠ эфир). Красный только когда вывод включён: LIVE, играющая песня, значок сета в боковой панели, Stop Output. При выключенном выводе значок сета и играющая песня серые.
